# 🐾 VetRoutes: Gestor de Rutas de Grafos para Veterinaria a Domicilio


Aplicación móvil desarrollada en Flutter diseñada para optimizar la logística diaria de servicios veterinarios profesionales (tanto consultas a domicilio como visitas a centros veterinarios).

## 🚀 Características Principales

* Gestión de Nodos Interactiva: Permite agregar, eliminar y mover puntos geográficos (domicilios y clínicas) directamente sobre un lienzo digital usando gestores de gestos.

* Trazado de Aristas Dinámicas: Conexión visual entre nodos para planificar trayectos y rutas de traslado.

* Interfaz Intuitiva y UX Avanzada: Barra de navegación inferior con modos específicos y retroalimentación visual interactiva (cambio de tonalidades al seleccionar nodos de origen).

* Enfoque de Vida Real (Logística y Enrutamiento): Planteado como una solución al problema de optimización de rutas para profesionales en constante movimiento.

## 🛠️ Tecnologías Utilizadas
* Framework: Flutter (Dart)
* Renderizado Gráfico: CustomPainter y Canvas
* Control de Interacciones: GestureDetector
* Gestión de Estado: setState nativo
